# `data/cut/` — 中美关税战讨论语料

本目录是 ASCE-CoC 随项目分发的示例数据集，用于开箱即跑仿真：
**一份围绕中美关税战的公开社交媒体讨论语料**，以及基于该语料整理的参与者画像。

仿真启动时会读取这里的三个文件（路径在 `configs/*.yaml` 的 `data` 段配置）：

| 文件 | 内容 |
|---|---|
| `profiles.json` | 300 个智能体画像 |
| `posts.json` | 2683 条讨论语料（候选帖池） |
| `meta.json` | 话题背景文本与本次清洗的统计摘要 |

---

## 1. `profiles.json` — 智能体画像

**300 条**，每条对应一个可被实例化为智能体的用户画像。

| 字段 | 类型 | 含义 |
|---|---|---|
| `user_id` | int | **本项目重新分配的连续编号**（1–300），仿真内部主键 |
| `display_name` | str | 展示名，形如 `用户0001` |
| `age` | str | 年龄段，共 5 档 |
| `gender` | str | 性别，共 4 类 |
| `mbti` | str | 16 型人格之一 |
| `country` | str | 国家/地区，共 21 类 |
| `profession` | str | 职业大类，共 15 类 |
| `education` | str | 受教育水平，3 档 |
| `economic_status` | str | 经济状况，4 档 |
| `interested_topics` | list[str] | 长期关注的话题 |
| `influence_metrics` | object | `{like_count, retweet_count, influence_score}`，用于计算"平台影响力"措辞 |
| `is_real` | bool | 画像是否来自真实用户的历史发言（`true` 26 条，`false` 274 条为由语料合成） |
| `bio` | str | 一句话自我描述 |
| `persona` | str | 角色速写（人口学 + 职业 + 兴趣 + 平台角色） |

**分布概览**（用于判断样本是否均衡）：

```text
gender            女 101 / 男 96 / 非二元 60 / 不愿透露 43
age               31-50 66 / 6-12 62 / 13-19 59 / 51+ 59 / 20-30 54
country           中国 100 / 美国 100 / 日本 12 / 其余 18 类各 1–9
profession        15 类，最大类 27
education         大专本科 123 / 硕士及以上 90 / 高中及以下 87
economic_status   中产 86 / 低收入 79 / 工薪中产 75 / 高收入精英 60
mbti              16 类，最大类 25
interested_topics 国际关系 274 / 经济 265 / 时政 119 / 科技 84 / 政治 26
```

### 关于 `persona` 与 `bio`

这两个字段是**专为本项目重新构造的**，不是上游语料的原文：

* `persona` 由人口学、职业、教育、经济状况、MBTI、兴趣话题与影响力档位拼装而成，
  句式固定、只陈述客观属性。
* `bio` 由"关注话题 + 职业特征 + 平台参与方式"三部分拼装，
  并按 `user_id` 轮换措辞以保留个体差异。

这样处理的目的是让每个智能体都有一个**中性的出发点**：认知链要推导的立场、情绪与
观点，不能预先写在人设里，否则推理会退化成对题面的复述。

## 2. `posts.json` — 讨论语料

**2683 条**，正文长度 5–1238 字符（中位数 47），无空正文、无重复正文。

| 字段 | 类型 | 含义 |
|---|---|---|
| `post_id` | int | 原始编号，1–2683 连续 |
| `content` | str | 正文，中文 |
| `author_id` | int | 作者在本项目中的 `user_id`；**负数表示该作者不在 300 人参与池内** |
| `author_external` | bool | 作者是否属于池外用户（`true` 2052 条） |
| `conversation_id` | str | 会话编号，共 168 个会话，用于回放讨论串结构 |
| `source_field` | str | 该条在上游会话中的位置，见下表 |
| `in_reply_to_id` | int \| null | 上游数据中的被回复对象；本数据集内**全部为 `null`**，保留字段以对齐上游结构 |
| `topic` | str | 话题标识，全部为 `cut` |
| `timestamp` | str | 上游时间戳 |

`source_field` 分布：

| 取值 | 条数 | 在上游讨论中的位置 |
|---|---:|---|
| `original_post` | 167 | 话题发起帖 |
| `context_post` | 1106 | 上下文发言 |
| `target_post` | 1410 | 被回应的发言 |

三类合计 2683 条。虽然顶层发起帖只有 167 条，但全部 2683 条都是**独立的用户发言**，
因此默认配置把它们统一作为候选帖池（`simulation.pool_source_fields`），
以支撑较长轮次的仿真；`simulation.seed_source_fields` 默认只取 `original_post`，
让每轮新增的话题由"发起帖"驱动。

> **容量提示**：语料规模决定了可支撑的仿真规模。2683 条候选帖在
> `100 agents × 20 ticks` 下平均复用约 5 倍，在 `300 × 100` 下约 112 倍。
> 需要更低复用率时，请先扩充 `posts.json`。

## 3. `meta.json` — 背景与清洗摘要

| 字段 | 含义 |
|---|---|
| `topic` | 话题标识 `cut` |
| `background` | 话题背景说明文本，会被注入每个智能体的 prompt |
| `profiles` | 画像处理统计（总数、真实/合成条数、被剔除的字段清单） |
| `posts` | 语料统计（总数、按 `source_field` 分布、池外作者数、长度区间） |
| `ban_leaks` | 清洗后的敏感标签自查结果，本数据集为**空数组**（表示零残留） |

## 4. 去标识化处理

本目录的数据经过以下处理后才随项目分发：

1. **用户重新编号**。所有用户获得新的连续 `user_id`（1–300）与展示名
   `用户0001` 形式。上游数据集中"真实用户"与"合成用户"两套编号存在区间重叠，
   直接沿用会导致帖子归属错乱，因此统一重新发放。
2. **移除全部认知标签字段**。上游数据带有情感/思维/立场/意图等分类标签，
   并把这些标签渲染进了自然语言描述。本项目将其全部剔除，包含：
   `cognitive_profile`、`information_style`、`communication_style`、
   `media_trust`、`persuasion_susceptibility` 等 11 个字段，
   并对 `persona` / `bio` 做了**整段重建**（而非仅删字段），
   避免标签以自然语言形式残留。`meta.json` 的 `ban_leaks` 记录了自查结果。
3. **剥离来源溯源字段**。清洗阶段会用到上游的用户编号来完成作者映射，但
   **写出前全部剥离**，最终交付的 `profiles.json` 与 `posts.json` 中不含任何
   指向上游账号的标识（`source_name` / `source_id` / `author_source_id`）。
   清洗脚本 `scripts/prepare_data.py` 的 `strip_source_fields()` 负责这一步。

## 5. 数据性质与合规

* 本数据集为**公开社交媒体讨论语料**的整理产物，话题为中美关税战相关的公共政策讨论。
* 数据仅包含公开可见的讨论内容与由之整理的画像属性，不含账号凭证、联系方式等直接身份信息。
* 数据集中包含**各年龄段的样本**。不同国家/地区对未成年人相关数据的处理要求不同，
  正式发表、商用或面向特定场景部署前，请按目标场景自行完成合规审查。
